# PlanetForge

**▶ Play it live: https://friedsalad21.github.io/PlanetForge/**

Procedural three.js space from 64-bit seeds: 30 planet types, rings, cratered moons, 9 star types (including binaries and pulsars), asteroid belts, black holes and nebula skies. The seed in the URL hash makes worlds shareable.
